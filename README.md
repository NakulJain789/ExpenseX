# ExpenseX

> Frontend-only prototype built for Smart India Hackathon (SIH) — Problem Statement ID: **USICT024**

This is a **UI/UX prototype demo**. It showcases the proposed user flow and interface for our solution. Backend integration, real APIs, and database persistence are **not yet implemented** — data shown is mocked/static for demonstration purposes.

---

## 🚀 Problem Statement

**Smart Student Expense & Group-Bill Splitting System with OCR Receipt Parser**

Students often struggle to track personal spending and settle shared expenses (rent, groceries, outings) with roommates or friends. ExpenseX aims to simplify this with an intuitive expense tracker, group-bill splitting, and OCR-based receipt scanning to auto-log expenses.

---

## 💡 Our Solution

ExpenseX is a student-focused expense management app that lets users track personal spending, split group bills fairly among friends/roommates, and scan receipts via OCR to automatically extract and log expense details — removing the need for manual entry.
